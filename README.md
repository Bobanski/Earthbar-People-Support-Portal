# Earthbar People Support Portal — deployment

This public repository contains only the reviewed static browser artifact for the
Earthbar People Support Portal. It contains no database rows, migrations, evidence
files, service credentials, or source-repository history.

Authentication and authorization are enforced by the portal's Supabase backend.
Loading this site does not grant access to HR dashboards or case data.

Release provenance and file checksums are recorded in `SOURCE_RELEASE.md`.
